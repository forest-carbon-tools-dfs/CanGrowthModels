# **TIPSY Application Documentation Updates FY 2023-2024**

The following Table Interpolation for Stand Yields (TIPSY) applications were updated in fiscal year 2023-2024. Documentation updates are summarized below.

- TIPSY 4.6 (March 2024)
- BatchTIPSY Composer 1.3 (March 2024)
- Site Tools 4.3 (March 2024)
- Plotsy 2 (March 2024)

## 1. TIPSY 4.6

About TIPSY Window

TIPSY 4.6 (March 2024) had minor updates from TIPSY 4.5 (March 2023). The updates include:

## **Software Improvements**

1. House Keeping Items
2. Windows 11 testing
3. What's New menu item added to the help menu (launches PDF)
4. Export Regime button
5. Updated TIPSY45 TCL file created in TIPSY to include the BTC linkage column
6. Update Plotsy button to check for either Plotsy 2 or Plotsy running
7. Index and Database remain unchanged

**What's New** - Updates are summarized in a "What's New" pdf document, accessible from the Help menu item. A new "What's New" menu item was added as part of the update in March 2024.

**Change log** - A changelog.txt file has also been included with the TIPSY 4.6 install summarizing the updates to March 2024.

# 4. **Plotsy 2**

About - Plotsy 2

Plotsy 2.1 (March 2024) was updated from Plotsy 2.0 beta (February 28, 2022). Plotsy 2 is an update to the earlier version Plotsy 1, providing expanded graphing functionality for use mainly by forest researchers wanting to compare and report growth and yield results. The March 2024 updates include:

## **Software Improvements**

1. Updated About screen Ministry of Forests (MOF) Logo.
2. Updated MOF Name.
3. Updated Copyright, version number, version date.
4. Fix crashes when creating new graph.
5. Fixed legend names not looking up `[ColumnName]`.
6. Fixed showing colour in column properties.
7. X axis label "()" updated when you reselect x-axis on main edit graph page.
8. Replaced "graph" menu with buttons on the toolbar.
9. Keep graph full screen (single or overlay mode) when resizing app.
10. Locked all graphs to same axis scale.
11. Export ASCII.
12. Double click data source to rename.
13. Complete Export Image/EMF feature.
14. Updated default templates.
15. Corrected Bar Graph Issues.
    - Corrected issues with creating new bar graphs, not requesting rows.
    - Corrected x-axis not working correctly on bar charts.
    - Corrected stacked graphs - bars were not drawn correctly.
    - Corrected group rows / fix x-axis in this mode too.
    - Corrected bar-uncheck "all items" when range is selected.
16. Prepared a Plotsy 2 interim User Guide, explaining functional upgrades from Plotsy to Plotsy 2.
