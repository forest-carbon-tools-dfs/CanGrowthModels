# **Release Note and Installation Guide – June 14, 2023**

## **Version Update**

The TIPSY version 4.5 software package (April 4, 2023) replaces the previous TIPSY version 4.5 released on March 2, 2022. The update from the previous version includes the new BatchTIPSY Composer v 1.2.0.0 Beta (64 bit) version. This program has been developed to meet new standard of modelling requirements for managed stand yield tables in BC. It provides improved batch processing capabilities over the earlier versions of BatchTIPSY and it can run as a separate program from TIPSY.

## **Download**

To download the TIPSY V4.5 – April 4, 2023 software package visit the Ministry of Forests <u>Software Download Website</u>.

## **Installation**

The TIPSY 4.5 package includes the programs:
- TIPSY
- Plotsy
- Plotsy2 (Beta)
- Fansier
- SiteTools
- TIPSY to CBM
- BatchTIPSY Composer Beta (BTC)

After running the self-installation file **TIPSY4.5.msi** the program will create a TIPSY 4.5 directory into `C:\program files\` and the following subdirectories: BTC, CBM, Fansier, Plotsy, Plotsy2, SiteTools and TIPSY. The programs and database versions are:

a. TIPSY 4.5.4, March 4, 2022
b. BCMOF Standard Database, March 2023
- Trembling Aspen TASS v2.07.55WS (Apr 2014 - Oct 2017)
- Western Redcedar TASS v2.05.24f (Apr 2014 - Jul 2021)
- Red Alder TASS v2.07.28WS (Apr 2014 - Mar 2018)
- Coastal Douglas-fir TASS v2.05.24f (Apr 2014 - Apr 2014)
- Interior Douglas-fir TASS v2.07.73WS (Apr 2012 - Jul 2021)
- Coastal Western Hemlock TASS v2.05.24f (Apr 2014 - Apr 2014)
- Interior Western Hemlock TASS v2.06.54DS (Apr 2014 - Jul 2021)
- Non-Commercial TASS v2.07.55WS (Apr 2014 - Oct 2017)
- Lodgepole Pine TASS v3.01.13W (Feb 2017 - Jul 2021)
- Sitka Spruce TASS v2.06.54DS (Apr 2014 - Apr 2014)
- White Spruce TASS v3.01.15W (Jul 2017 - Jul 2021)
c. SIndex 1.54, March 15. 2022 (latest 32bit version)
d. Plotsy 1.30, March 1, 2022 (default plotting program)
e. Plotsy 2.00, February 28, 2022 (secondary plotting program for testing only)
f. Fansier 2.1, March 30, 2022 (cost/price adjustments for 2006$ with option for 2020$)
g. SiteTools 4.2, June 17, 2021 (using latest 32-bit version)

---



h. TIPSYtoCBM 1.07, August 26, 2020
i. BatchTIPSY Composer (64 bit) v 1.2.0.0 Beta, March 31, 2023

Support is provided for the MS Windows (64bit) 10 and 11 operating system. We recommend that you close any other Windows applications before beginning the installation. If you wish to remove any previous versions of TIPSY, use the TIPSY uninstall icon if you have one, or the Windows Control Panel's Add/Remove function. You might want to keep previous versions of TIPSY/Batch TIPSY for business reasons. TIPSY 4.5 can read interactive (.tip), batch (.btp) files created with previous versions of TIPSY and BatchTIPSY.

**Note:** The installation program only creates a TIPSY shortcut icon on your desktop. The rest of the program icons can be manually added to your desktop or pin on the task bar after opening.
